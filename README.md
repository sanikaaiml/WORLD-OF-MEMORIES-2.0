# WORLD OF MEMORIES 2.0
World of Memories  World of Memories is an AI-powered web application designed to help users preserve, relive, and creatively recreate their special memories. Users can create digital memories by adding an event, description, emotion, date, and optional photograph. The application stores these memories in a personalized timeline and generates an AI-inspired story based on the user’s memory.
The project also includes an AI Image Generation feature that transforms the memory description into a visual representation, creating an immersive way to revisit meaningful moments.
✨ Key Features
- 🔐 User Registration & Login – Securely create an account and access personal memories.
- 📝 Create Memories – Add memorable events with descriptions, emotions, dates, and photographs.
- 📅 Memory Timeline – View memories chronologically in a beautiful timeline interface.
- 🤖 AI Story Generation – Automatically create a personalized story from the details of a memory.
- 🎨 AI Image Generation – Generate an AI-based visual representation of a memory.
- 🖼️ Photo Upload – Upload personal photographs associated with memories.
- 💾 SQLite Database – Store user accounts and memories locally.
- 🎨 Premium UI/UX – Soft colors, gradients, animations, cards, and a modern memory-inspired design.
- 📱 Responsive Design – Designed to work across different screen sizes.

🎯 Project Objective
The main objective of World of Memories is to combine Artificial Intelligence with personal memories to create a digital space where users can preserve important life experiences and experience them in a more emotional and creative way.
Instead of simply storing photographs and text, the application attempts to transform memories into stories and visual experiences, making the memories more interactive and meaningful.
